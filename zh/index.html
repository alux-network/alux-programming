    ALUX 编程指南

    注

    本书将介绍理解并参与 ALUX 语义优先代码库所需的基础，从指称设计的一项核心原则讲起：先定义程序的含义，再决定程序如何运行。

    沿袭 Conal Elliott 的思路，本书将计算视为清晰的数学对象，而不是不透明的步骤序列。

    规范以简单、可组合的能力 trait表达，用来描述程序意味着什么。解释器提供可互换的方式来实现这些含义。

    这样一来，软件的组合规则、实现义务和有效等式都更容易理解和测试。

    机制与含义

    概念与洞见用于说明实用的编程机制。指称设计则说明如何判断这些机制应当保留什么。

    如何阅读本书

    本书分三个层次阅读：

    • 语义视角介绍指称与组合性、定律与解释，以及含义与表示之间的关系。
    • Rust 中的语义驱动设计将这一视角落实为小型能力、派生扩展、一阶程序和轻量级解释器。
    • 概念与洞见介绍重要的执行模型、编码、变换与联系。

    语义原则不依赖特定语言。Rust 是主要实现语言；一条并发语言处理流水线将这些原则与 Tolang 联系起来。

    本书适合谁

    • 希望复杂软件在不断演进时仍能保持模块化、可组合、可测试且易于维护的程序员。
    • 希望连接范畴论、类型系统与程序设计的开发者。
    • 熟悉表示与操作技术的读者——例如自由单子、延续传递风格（CPS）和去函数化——希望理解这些机制如何服务于语义优先设计，而非定义它。
    • 熟悉依赖类型与证明导向编程，并希望在编写高性能 Rust 时运用这套思维方式的读者。
    • 需要阅读语义优先的 Rust 规范，并理解如何编译并发语言，而不以编译器本身作为语言定义依据的贡献者。
