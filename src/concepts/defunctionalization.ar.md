# إزالة الدوال {#defunctionalization}

```admonish tip title="ذات صلة"

المفاهيم: [الموناد الحر](free_monad.md)، [أسلوب تمرير الاستمرار](cps.md)  
الرؤى: [جبر EVM](../insights/evm-alg.md)
```

```admonish note title="الموضع الدلالي"
تغيّر إزالة الدوال التمثيل مع استهداف الحفاظ على سلوك البرنامج. وفي التصميم الذي يبدأ بالمعنى، تفيد القيم المولدة من الرتبة الأولى عندما يحتاج مفسر آخر إلى فحص العمليات أو تركيبها قبل التنفيذ.
```

## التعريف {#definition}

إزالة الدوال تحويل برمجي يستبدل الدوال عالية الرتبة ببنية بيانات من الرتبة الأولى تمثل الدوال الممكنة، مع دالة مفسر تطبقها.

## الدافع {#motivation}

لا تستطيع بعض اللغات أو المترجمات أو أزمنة التشغيل معالجة الدوال عالية الرتبة بكفاءة أو إطلاقًا. تتيح إزالة الدوال جعل البرنامج من الرتبة الأولى بالكامل، فيسهل تجميعه أو تحليله أو تسلسله أو تشغيله في بيئات مقيدة.

## العملية {#the-process}

1.  حدد كل الدوال المحتملة عالية الرتبة التي يمكن إنشاؤها وتمريرها.
2.  خصص لكل دالة منها وسمًا فريدًا في تعداد أو نوع مجموع، مع البيانات اللازمة لتشغيلها.
3.  استبدل قيم الدوال بهذه الوسوم.
4.  عرّف دالة `apply` تتلقى وسمًا ووسائط الدالة، ثم تطابق النمط على الوسم لتشغيل الكود الصحيح.

## مثال في Rust {#example-in-rust}

قبل: استخدام إغلاق

```rust,noplayground
let k: Box<dyn Fn(i32) -> i32> = Box::new(|x| x + 1);
println!("{}", k(41));
```

بعد: صيغة أزيلت منها الدوال

```rust,noplayground
enum Cont {
    Add1
}

fn apply(c: Cont, x: i32) -> i32 {
    match c {
        Cont::Add1 => x + 1,
    }
}

println!("{}", apply(Cont::Add1, 41));
```

## الخصائص {#properties}

*   أصبحت جميع الدوال ممثلة ببيانات بسيطة.
*   أصبح البرنامج من الرتبة الأولى بالكامل.
*   تحل دالة `apply` محل استدعاءات الدوال المباشرة.

## التطبيقات {#applications}

*   تبسيط خلفية المترجم: تولد مترجمات كثيرة شيفرة بأسلوب تمرير الاستمرار ثم تزيل دوالها.
*   تسلسل الدوال: يمكنك إرسال وسم التعداد عبر الشبكة أو تخزينه في ملف.
*   التحليل الساكن: يسهل الاستدلال على الشيفرة من الرتبة الأولى.
*   اشتقاق المفسرات: تقود إزالة الدوال طبيعيًا إلى نمط المفسر.

## العلاقة بأسلوب تمرير الاستمرار {#relation-to-cps}

في أسلوب تمرير الاستمرار (CPS)، تكون الاستمراريات دوالًا عالية الرتبة. وتحول إزالة الدوال شيفرة CPS هذه الاستمراريات إلى مجموعة منتهية من الحالات في تعداد مع دالة تطبيق.

## العلاقة بالمونادات الحرة {#relation-to-free-monads}

يمكن ربط تمثيلات مناسبة للموناد الحر باستمراريات أزيلت دوالها في برامج محولة إلى أسلوب تمرير الاستمرار. إنها صلة وثيقة، وليست تطابقًا عامًا بين البناءين.

## التطبيق على مستوى الأنواع {#type-level-application}

يمكن لإزالة الدوال أيضًا ترميز التطبيق على مستوى الأنواع في اللغات التي تفتقر إلى أنواع عالية الرتبة أصلية. وتطبق [تجربة جبريات الكائنات في C#](https://github.com/tgrospic/object-algebras) هذا الترميز الخفيف عبر `App<F, a>` للتعبير عن جبريات الفونكتور والتطبيقي والموناد والآثار.
