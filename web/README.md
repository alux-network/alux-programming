# ALUX Programming — local design preview

An independent presentation layer over the complete original `../src` book, with an illustrated frontispiece, a spatial chapter atlas, four part overviews, full-book search, a composition workshop and full-sheet HTML page turning. Original Markdown, diagrams, formulas, technical examples, embedded talks and the mdBook publishing workflow remain untouched.

Install with `pnpm install`, then run `pnpm dev` and open `http://127.0.0.1:4173`. `pnpm build` renders the full book, syntax highlighting, KaTeX, callouts and direct HTML chapter routes. `pnpm preview` serves the production build. Node 22+ is recommended.

Only local work is authorized at this stage. Do not push, publish or change the existing deployment workflow until the owner approves this design.

The logo copies in `public/` preserve the owner's official artwork. The masthead pairs a generated patinated-bronze interpretation of that geometry with live literary typography. Night reading uses a generated light-bronze counterpart. Neither mark has a badge or backing plate. The illustrated book uses an integrated foil impression. Original technical diagrams and chapter illustrations are retained; the old decorative title logo is superseded by the masthead.

Reading supports keyboard page turns, touch swipes, adjustable type, night reading, bookmarks, restored position and a continuous reading option. Long technical blocks retain their complete contents in independent scroll regions. Reduced-motion preferences skip animated turns. Production chapter routes also include readable no-JavaScript fallbacks.

The desktop directory stays visible alongside the book and can be collapsed. Smaller screens have a labeled Contents button. Tables continue between whole rows with repeated column headers. Navigation uses a soft full-viewport paper fold with a separate paper back, while reading spreads turn at the spine.
