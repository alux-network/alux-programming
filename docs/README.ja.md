# ALUX プログラミングガイド

![ALUX プログラミングガイド](../public/social/alux-programming-ja.jpg)

プログラムが何を意味するかを定めてから、どう実行するかを選ぶための本です。Conal Elliott の指示的設計をもとに、合成、法則、インタープリターを説明し、Rust のケイパビリティ trait と具体例で実装につなげます。

## 本書の内容

- 意味論的な視点：指示、合成性、法則、解釈、依存型。
- Rust における意味による設計：ケイパビリティ、導出された操作、インタープリター、根拠、コンパイラーパイプライン。
- 概念：操作的意味論、自由モナド、継続、非関数化などの仕組み。
- 考察：それらの仕組みと、プログラムの意味や実行との関係。

## 読む

ウェブ版は11言語に対応し、ページをめくる魔法の本と、スクロールして読むシンプルな技術文書の2つの表示を提供します。文字サイズ、明暗テーマ、検索、ブックマークに対応し、手動で選んだ言語と各章の読書位置を端末に保存します。

魔法の世界では、現在の章を必要に応じてページに分割します。ページ番号は章内の進行状況を示します。文字サイズやウィンドウサイズを変えると再配置され、相対的な読書位置が保たれます。

[日本語版を開く](https://programming.alux.network/ja/)
