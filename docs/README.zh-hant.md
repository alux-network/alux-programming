# 《ALUX 程式設計指南》

![ALUX 程式設計指南](../public/social/alux-programming-zh-hant.jpg)

這本書從程式的含義出發談設計：先定義清楚的語義、組合規則和定律，再選擇實作方式。書中沿用 Conal Elliott 的指稱設計思路，透過 Rust 的能力 trait、解釋器和證據落實到程式碼中。

## 書中內容

- 語義視角：指稱、組合性、定律、解釋與依賴型別。
- Rust 中的語義驅動設計：能力、衍生操作、解釋器、證據與編譯器流水線。
- 概念：操作語義、自由單子、延續、去函式化等程式設計機制。
- 洞見：這些機制與程式含義、執行方式之間的聯繫。
