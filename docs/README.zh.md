# 《ALUX 编程指南》

![ALUX 编程指南](../public/social/alux-programming-zh.jpg)

这本书从程序的含义出发讲设计：先定义清楚的语义、组合规则和定律，再选择实现方式。书中沿用 Conal Elliott 的指称设计思路，通过 Rust 的能力 trait、解释器和证据把它落到代码中。

## 书中内容

- 语义视角：指称、组合性、定律、解释与依赖类型。
- Rust 中的语义驱动设计：能力、派生操作、解释器、证据与编译器流水线。
- 概念：操作语义、自由单子、延续、去函数化等编程机制。
- 洞见：这些机制与程序含义、执行方式之间的联系。
