# Guía de programación de ALUX

![Guía de programación de ALUX](../public/social/alux-programming-es.jpg)

Este libro explica cómo definir primero el significado de un programa y elegir después cómo ejecutarlo. Sigue el diseño denotacional de Conal Elliott y lleva la composición, las leyes y los intérpretes a ejemplos en Rust mediante traits de capacidades.

## Contenido

- La perspectiva semántica: denotaciones, composicionalidad, leyes, interpretaciones y tipos dependientes.
- Diseño por significado en Rust: capacidades, operaciones derivadas, intérpretes, evidencias y procesos de compilación.
- Conceptos: semántica operacional, mónadas libres, continuaciones, desfuncionalización y mecanismos relacionados.
- Reflexiones: la relación de estos mecanismos con el significado y la ejecución de los programas.

## Lectura

El lector web admite once idiomas y ofrece dos interfaces: un libro mágico con páginas y una vista sencilla de documentación con desplazamiento. Incluye ajuste del tamaño de letra, temas claro y oscuro, búsqueda y marcadores. El idioma elegido manualmente y el progreso de cada capítulo se guardan localmente.

En el mundo mágico, el capítulo actual se pagina cuando es necesario. Los números de página indican el progreso dentro de ese capítulo. Al cambiar el tamaño de letra o de la ventana, el contenido se redistribuye conservando la posición relativa de lectura.
